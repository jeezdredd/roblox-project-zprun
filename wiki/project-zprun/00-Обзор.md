# Task Force Z — обзор

Кооперативный endless runner (1–3 игрока) в сеттинге зомби-апокалипсиса. Военная база-ангар → вертолёт-лобби → забег по процедурным биомам → награды.

**Название:** Task Force Z (выбрано из 18 кандидатов, военный угол: отряд ликвидации).

## Стек
- Luau `--!strict` везде, Rojo (`default.project.json`), Wally (зависимостей пока нет), Selene, Rokit (версии в `rokit.toml`)
- `src/server` → ServerScriptService, `src/client` → StarterPlayerScripts, `src/shared` → ReplicatedStorage.Shared, `src/replicatedfirst` → ReplicatedFirst
- Данные игроков: in-memory на сервере (ProfileStore подключим позже, DataStore требует публикации)

## Принципы
1. Сервер — source of truth. Клиент не доверенный, всё валидируется на границе (тип/диапазон/rate-limit)
2. Data-driven: контент в конфиг-модулях (`src/shared/config/`), не в коде систем
3. Модульность: система = ModuleScript с чистым API
4. RemoteEvents централизованы в `src/shared/net/Remotes.luau`, без магических строк
5. Без комментариев в коде; PascalCase модули, camelCase локальные
6. Никакого pay-to-win

## Игровой флоу (текущий)
Загрузочный экран (ReplicatedFirst) → тайтл «TASK FORCE Z» → предупреждение о контенте → ангар (хаб) → ProximityPrompt на вертолёте → лобби отряда (карта/сложность/приватность/модификаторы, лидер = первый севший) → отсчёт → телепорт на трассу → бег от первого лица, зомби, дистанция → смерть = катсцена пожирания → YOU ARE DEAD → результаты (XP/кредиты — пока заглушка от дистанции) → возврат в ангар или продолжение (Robux-стаб).
