# Архитектура

## Сервер (`src/server/systems/`)
- **FlowService** — фаза игрока (attribute `FlowPhase`: Hub | Mission), настройка Humanoid по фазе (скорость/прыжок, `BreakJointsOnDeath = false`), принудительный телепорт в ангар при спавне в Hub
- **HangarBuilder** — процедурный ангар: пол/стены (Concrete/Metal), 3 вертолёта (кабина, кокпит, хвост, винты, лыжи) с ProximityPrompt и билбордом статуса
- **VendorStands** — 5 заглушек торговцев: Soda Machine, Bubblegum, Weapon Dealer, Gunsmith, Medbay («Coming soon»)
- **SquadService** — стейт-машина отряда (Empty→Filling→Launching→Departed), лидер = members[1], валидация всех изменений конфига (лидерство, состояние, id, rate-limit 12/с), приватность Solo/Friends/Public (`IsFriendsWithAsync` с кэшем — **FriendCache**), отсчёт запуска, общий seed
- **MissionService** — старт/стоп миссии отряда: конфигурация спавнера по карте, Night-освещение, телепорт с латеральным разбросом, death handler
- **MissionState** — активная миссия, участники, модификаторы
- **MissionConfig** — текущая сложность (+ Workspace attribute `Difficulty` для отладки)
- **DistanceTracker** — серверная дистанция (проекция на RUN_DIRECTION, монотонная), рост WalkSpeed, leaderstats
- **ChunkSpawner** — план локаций (биом 4–8 чанков), переходные чанки (лерп цвета + смешение пропсов, 2 шт), пулинг чистых чанков по locationId, спавн впереди/деспавн позади
- **ChunkFactory** — генерация чанка: пол/стены/обочины-«тротуары», разметка, процедурные пропсы (здания с неоновыми окнами / деревья / руины, машины/камни на полосе). Слот `ReplicatedStorage.PropTemplates` — модель `buildings`/`trees`/`ruins` заменяет генератор
- **ZombieAI** — спавн по чанкам, агро по сложности (`aggroDistance`), преследование **запаздывающей** позиции (джюк зигзагами: Walker 0.75с, Runner 0.35с), урон касанием с кулдауном, приманка к трупу (`swarmCorpse`), `SetNetworkOwner(nil)`
- **ZombieFactory** — риг из Part-ов (`RequiresNeck = false`!)
- **DeathService** — обработка смерти: поза «на спине» (анкор + tween), приманка зомби, награды (дистанция × множитель), выбор return/continue (таймаут 30с), ревайв на месте смерти
- **TrackBuilder** — стартовая платформа

## Клиент (`src/client/`)
- **controllers/**: FlowController (вкл/выкл контроллеров по фазе), InputController (A/D + стрелки, ContextActionService), RunController (`Humanoid:Move` каждый кадр + wrap-телепорт у стен), CameraController (**принудительное первое лицо** в забеге, персонаж скрыт через LocalTransparencyModifier, при смерти отдаёт управление), SquadController, DeathController (катсцена: крик, пожирание 5 тиков гора, чернота 6с, YOU ARE DEAD, результаты)
- **systems/**: SettingsService (client-only store + observe), SettingsApply, MusicController (SoundGroup Master/Music, слоты asset ID, фейд в миссии), FpsCounter, GoreController (кровь при уроне + виньетка), DeathGore (лужа, брызги, гибы, feastTick)
- **ui/**: SquadConfigGui, SettingsGui (Audio/Graphics/Content), HudGui (⚙ + 🔊 + клавиша M), GoreWarningGui
- **replicatedfirst/**: Boot (лоадер + тайтл, скип по Enter/Space), BootConfig, BootState

## Shared (`src/shared/`)
- **config/**: GameConstants, DifficultyConfig (Easy/Medium/Hard: chase, speedMult, rewardMult, aggroDistance), LocationsConfig (City/Forest/Wasteland), MapsConfig (маршруты → locationIds), ModifiersConfig (FastZombies/Night/Forest), ZombiesConfig, VendorsConfig, HangarConfig, SettingsConfig, AudioConfig (слоты: MENU_MUSIC_ID, MISSION_MUSIC_ID, DEATH_SCREAM_ID)
- **net/Remotes.luau** — реестр: SquadSnapshot/UpdateConfig/ToggleModifier/Launch/Leave, DeathBegan/DeathChoice
- **types/**: Squad, Flow; **util/**: LaneSectionFactory, RewardMultiplier

## Потоки данных
- Лобби: клиент шлёт intent → сервер валидирует → snapshot всем участникам (FireClient)
- Смерть: Humanoid.Died → DeathService → поза+приманка → DeathBegan(rewards) → клиент рендерит катсцену локально (гор — по личным настройкам клиента) → DeathChoice → return в ангар / continue на месте
- Gore рендерится только на клиенте — настройка каждого игрока авторитетна для его экрана
