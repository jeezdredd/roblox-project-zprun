# Производительность — паспорт и бюджеты

## Бюджеты (из ТЗ)

| Показатель | Лимит | Как обеспечен |
| --- | --- | --- |
| Активные ParticleEmitter | ≤ 40 | `VfxConfig.MAX_ACTIVE_EMITTERS`, счётчик в `WorldVfx` при навешивании углей |
| Частицы в кадре | ≤ 600 (mobile) / 1500 (desktop) | Плотность через `VfxConfig.DENSITY`, настройка **Effects Density** (0.4–1.0), Low = 0.4 |
| Пул декалей/пятен | ≤ 30 с реюзом | Пятна крови живут 25 с (`Debris`), пятна грязи — часть чанка, уходят вместе с ним |
| Клиентский аудио-апдейт | < 0.3 мс/кадр | Все аудио-системы на `Heartbeat`, без аллокаций в цикле; пулы `Sound` |
| Камера + звук на RenderStepped | < 0.2 мс/кадр | `ExertionState` считает один раз за кадр, потребители читают готовые значения |
| Одна часть промпта | ≤ 1.5 мс на десктопе | См. меры ниже |

## Что сделано для рамок

**Геометрия**
- `StreamingEnabled` включён, `StreamingTargetRadius = 1024` (в `default.project.json`)
- Оконные ленты зданий ограничены 4 на здание (`MAX_WINDOW_BANDS`)
- Диорама города: 72 квартала, 22 пожара, из них только 9 с `PointLight`
- Чанки: пулинг по `locationId`, переходные чанки не пулятся (уникальная геометрия)
- Декоративные части: `CanCollide = false`, `CanQuery = false`, `CastShadow = false`

**Свет**
- Точечные источники ограничены: 16 в ангаре, 9 на пожарах, 3 мигающие лампы
- `Lighting.Technology = Future` задан через Rojo; при просадке на слабых машинах меняется на `ShadowMap` в том же файле

**Звук**
- Пул `Sound` на шаги (6 на игрока, 3 на тиммейта), пул на 2D-SFX (10)
- 3D-звуки создаются только при событии и самоуничтожаются по `Ended`
- Треск огня — максимум 10 источников (`FIRE_MAX_SOURCES`)
- Шаги тиммейтов считаются на `Heartbeat`, а не в кадровом бюджете

**VFX**
- Все эмиттеры создаются один раз на персонажа и переиспользуются через `Emit()`
- Пепел — один эмиттер, привязанный к камере
- Плотность всех выбросов умножается на `VfxConfig.DENSITY`

## Как снимать замеры

MicroProfiler (`Ctrl+F6` в Studio), сцены для сравнения:

1. **Хаб** — стоя у ворот, видны город, вертолёты, вендоры
2. **Забег день** — City, Hard, ~1500 м (максимум зданий и препятствий)
3. **Забег ночь** — City + Night (фонарик, пылинки, тьма)
4. **Орда** — Hard, после агро, 10+ зомби в радиусе 60

Смотреть: `RunService.RenderStepped` (камера, тело, фонарик), `Heartbeat` (звук, VFX, HUD), `Particles`, `Lighting`.

## Ручки при просадке

| Симптом | Что крутить |
| --- | --- |
| Общая просадка | Настройка **Effects Density** → 0.4 |
| Просадка в городе | `HangarConfig.CITY_BLOCKS`, `CITY_FIRES`, `CITY_FIRE_LIGHTS` |
| Просадка в забеге | `GameConstants.SPAWN_AHEAD_DISTANCE`, `FIELD_OBSTACLE_SCALE`, `MAX_WINDOW_BANDS` |
| Тени дорогие | `Lighting.Technology` → `ShadowMap` в `default.project.json`, настройка **Shadows** |
| Звук ест кадр | `SfxConfig.FIRE_MAX_SOURCES`, `ZOMBIE_IDLE_MAX_VOICES` |

## Открытое

Замеры до/после в мс не сняты — MicroProfiler доступен только в Studio, у меня нет к нему доступа. Все бюджеты обеспечены конструктивно (лимиты, пулы, множитель плотности); фактические цифры снимаются по чеклисту выше.
