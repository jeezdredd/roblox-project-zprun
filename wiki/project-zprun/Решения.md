# Ключевые решения

- **Один place, транспорт абстрагирован.** TeleportService не работает в Studio-плейтесте — полный флоу тестируется в одном place (телепорт CFrame между зонами). Реальные телепорты подключатся позже без переписывания систем
- **Движение Humanoid-based.** `Humanoid:Move()` каждый кадр с клиента; персонаж под network ownership клиента (нативная репликация). Серверная валидация — дистанция считается сервером по позиции
- **Wrap у стен** — по координате X на клиенте (порог от стены), не Touched (пропускает на скорости). Физические стены остаются страховкой
- **Зомби серверные** (`SetNetworkOwner(nil)`), преследуют запаздывающую позицию игрока — джюк зигзагами это контрплей. Задержка per-тип (Walker 0.75с / Runner 0.35с). Агро-порог per-сложность: Hard с нуля, Medium 500, Easy никогда
- **Кастомному ригу зомби обязателен `RequiresNeck = false`** — иначе Humanoid мгновенно убивает модель без шейного Motor6D
- **Gore рендерится клиентом.** Сервер шлёт факт (DeathBegan), каждый клиент решает по своим настройкам. Иначе чужой тумблер не спрятал бы серверные гибы
- **Первое лицо принудительно в забеге** (решение геймдизайна — third person «портит суть»). Персонаж скрывается через `LocalTransparencyModifier` каждый кадр; при смерти видимость возвращается для катсцены
- **Смерть управляемая:** `BreakJointsOnDeath = false` (не рассыпается), сервер анкорит корень и укладывает на спину tween-ом; `Players.RespawnTime` большой — респавн только через `LoadCharacter` по выбору игрока
- **Настройки client-only, без ремоутов** — косметические (громкость/тени/гор), серверу не нужны. In-memory store с observe API, готов под ProfileStore
- **Аудио — слоты asset ID в конфиге.** Из среды разработки нельзя проверить/загрузить ассеты; без ID тишина без ошибок. После Open Cloud key — загрузка через API
- **Лобби:** членство отряда только в серверной таблице (не Seat.Occupant — одноместный и ненадёжный), лидер = members[1], промоушен при выходе, отмена отсчёта при уходе лидера, Solo блокируется при 2+
- **Множитель наград** считается на клиенте для отображения и пересчитывается сервером при начислении
- **Коммиты от имени владельца** без упоминаний Claude
