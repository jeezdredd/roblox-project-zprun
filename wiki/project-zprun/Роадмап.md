# Роадмап

Порядок примерный, обсуждается по ходу.

## Ближайшее
1. **Текстуры/ассеты** — ждём Open Cloud API key от владельца (scope asset:read+write) → загрузка бесплатных CC0 текстур (ambientCG и т.п.) и звуков через API, подключение по asset ID (MaterialVariant/Texture, AudioConfig)
2. **Экономика v1** — Credits начисляются на сервере по итогам забега, кошелёк в UI, in-memory store с API под ProfileStore
3. **Спектейт** — при смерти в отряде наблюдение за живыми до конца забега

## Средний горизонт
4. **Солдаты/жизни** — до 3 активных солдат, здоровье/энергия, потери при смерти в забеге, лечение в Medbay, эвакуация вертолётом (с усложнением)
5. **Торговцы v1** — газировка/жвачка (случайный бафф на 1 забег), базовая покупка
6. **Оружие** — покупка (Weapon Dealer), улучшение (Gunsmith), стрельба по зомби, зомби умирают → гор уже готов
7. **Пикапы на трассе** — бензопила, граната; статус-эффекты (таблица множителей с длительностью)

## Дальше
8. **Скины** — режимные скины персонажей, дефолтные + разблокируемые
9. **ProfileStore** — персистентность (после публикации игры)
10. **Публикация** — опросник зрелости (стилизованная кровь/расчленёнка → Moderate violence), DeveloperProduct для Continue, реальные Robux
11. **Монетизация** — косметика, battle pass, удобства. Без P2W
12. **TeleportService** — если понадобится разделение hub/run на отдельные places (сейчас один place, транспорт абстрагирован)

## Идеи вне очереди
- Ночные фонарики (Tool или улучшение «фонарик на стволе»)
- Больше биомов и типов зомби (data-driven, добавление = запись в конфиг)
